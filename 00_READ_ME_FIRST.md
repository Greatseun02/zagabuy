## 💡 Usage Examples

### Typography

```tsx
// Display heading
<Typography variant="display" size="2xl" weight="bold">
  Main Title
</Typography>

// Body with custom color
<Typography color="muted-foreground">
  Secondary text
</Typography>

// Using custom HTML element
<Typography component="h1" color="primary">
  Page Title
</Typography>
```

### Button

```tsx
// Basic
<Button>Click</Button>

// With variant
<Button variant="secondary">Secondary</Button>

// With icon
import { Heart } from "lucide-react";
<Button startIcon={Heart}>Like</Button>

// With loading
<Button isLoading={isLoading}>Loading...</Button>

// Full width
<Button width="full">Submit</Button>

// Icon only
<Button size="icon"><Heart /></Button>
```
