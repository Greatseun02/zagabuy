## ✨ Key Features Reference

### Typography

- 2 variants (display, text)
- 6 sizes (xs to 2xl)
- 4 weights (regular to bold)
- 10+ colors + custom
- 2 fonts (sans, mono)
- 7 components (p, span, h1-h6, div)

### Button

- 7 variants (primary, secondary, outline, ghost, destructive, link, transparent)
- 7 sizes (x-small to large, icon variants)
- 3 widths (auto, fit, full)
- Loading state with spinner
- Icon support (start, end)
- Dark mode
- Keyboard accessible
